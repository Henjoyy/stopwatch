# Getaway Clock

GTA 6의 바이스시티 석양 분위기를 입힌 웹 스탑워치입니다. 설치 없이 HTML 파일 하나로 동작합니다.

## 실행 방법

1. 저장소를 내려받습니다.
2. `GTA 스탑워치.html` 파일을 브라우저로 엽니다.

별도의 빌드나 서버는 필요 없습니다. 폰트(Anton, Oswald, Permanent Marker)를 Google Fonts에서 불러오므로 인터넷에 연결되어 있어야 원래 모습으로 보입니다. 오프라인에서도 동작하지만 기본 폰트로 표시됩니다.

## 기능

- **시작 / 정지 / 계속**: 시:분:초.1/100초 단위로 표시합니다.
- **랩**: 구간 시간과 누적 시간을 기록하고, 가장 빠른 랩은 초록색, 가장 느린 랩은 핑크색으로 표시합니다(랩이 3개 이상일 때).
- **리셋**: 시간과 랩 기록을 모두 초기화합니다.
- **단축키**: `Space` 시작/정지, `L` 랩, `R` 리셋

## 연출

- **WANTED 별**: 시간이 지나면 10초마다 별이 하나씩 켜집니다(5성 = 50초).
- **경찰 추격**: 별 개수에 따라 경찰차가 따라붙습니다. 12성은 1대, 34성은 2대, 5성은 3대입니다. 사이렌 불빛이 화면 가장자리에서 번쩍입니다.
- **도로 주행**: 시작하면 도로의 중앙선과 가로등이 흐르고, 핑크색 스포츠카가 달립니다.
- **랩 이펙트**: 랩을 누르면 니트로 부스트(앞바퀴 들기, 불꽃), 화면 번쩍임, 스피드 라인, 컨페티가 터지고 "LAP PASSED", "NITRO BOOST!" 같은 문구가 무작위로 나옵니다.

## 기술

- 순수 HTML, CSS, JavaScript (프레임워크와 외부 라이브러리 없음)
- 시간 계산은 `performance.now()`와 `requestAnimationFrame`을 사용합니다.
- 차량과 야자수, 스카이라인은 직접 그린 인라인 SVG입니다.
- 랩 이펙트는 Web Animations API로 구현했습니다.

## 참고

이 프로젝트는 팬 메이드 연출용 개인 프로젝트이며, Rockstar Games 및 Take-Two와 관련이 없습니다. 게임의 공식 이미지나 로고는 사용하지 않았습니다.
